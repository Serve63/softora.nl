# Persoonlijke Softora-sites

Twee zelfstandige one-pagers met dezelfde positionering en dienstverlening, live onder Softora:

- `servecreusen/` voor `softora.nl/servecreusen/`
- `martijnvandeven/` voor `softora.nl/martijnvandeven/`

Start de lokale preview vanuit de repo-root met:

```bash
node personal-sites/preview-server.js
```

Open daarna `http://127.0.0.1:4188/` om beide pagina's te kiezen.

De mappen zijn bewust zelfstandig gehouden binnen de Softora-server, zodat beide pagina's dezelfde huisstijl-assets en onafhankelijke layout kunnen behouden.
