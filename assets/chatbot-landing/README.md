# Chatbot — landingspagina

Publieke route: `https://www.softora.nl/chatbot`.

Start vanuit de root van deze werkmap met `node scripts/preview-seo-solution.js` en open http://127.0.0.1:4176/chatbot.

De chatbot-tegel op `/toekomst` verwijst naar deze pagina. Inloggen blijft apart op `/chatbot-login`. De SEO-pagina blijft bereikbaar via `/seo-solution`.

De gespreksdemo bevat drie situaties voor een expliciet fictieve interieurstudio. De vervolgvragen en reset werken lokaal met vaste voorbeeldantwoorden. Er worden geen API-aanvragen, berichten, klantgegevens of betaalde AI-generaties verstuurd.

De gedeelde stijl en menu-/tabbediening staan in `assets/service-landing/`. De vier eigen imagegen-illustraties staan in `images/`; de prompts staan in `docs/design/chatbot-landing-image-prompts.md`.
